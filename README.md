HOW TO PREVIEW
--------------
1. Unzip the folder.
2. Double-click index.html.
3. It will open in your browser.

HOW TO PUBLISH FOR $0
---------------------
Option A: GitHub Pages
1. Create a free GitHub account.
2. Create a new public repository, for example: tessy-real-estate.
3. Upload all files from this folder, keeping the assets folder intact.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and /root folder, then save.
7. GitHub will provide a free website address.

IMPORTANT
---------
- The site itself can be hosted for free.
- A custom .com domain is normally not free.
- Live MLS/IDX property search normally requires a paid IDX service and MLS approval.
- The Search Homes button currently scrolls to the buyer section. Later, replace that link with your IDX/MLS search URL.
- Property photos in the service cards are loaded from Unsplash over the internet.

EDITING QUICKLY
---------------
Open index.html in Notepad or another text editor.
Search for the text you want to change, replace it, and save.

PHOTO CROP
----------
The portrait size/crop is controlled in styles.css under:
.portrait-wrap
.portrait-wrap img
You can adjust object-position if you want the face higher/lower in the frame.
